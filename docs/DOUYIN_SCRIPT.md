# 抖音演示脚本（约 45 秒）

## 标题建议

Clash 不用关，Chrome 一键切换代理和直连

## 口播

> 开着 Clash 的时候，有些国内网站走代理反而打不开；关掉 Clash，海外网站又不方便。
>
> 我做了一个开源小插件。Clash 和 TUN 一直开着，Chrome 右上角直接选“代理模式”或者“直连模式”。
>
> 它的原理不是反复开关系统代理，而是在 Mihomo 里建立两个只监听本机的出口：一个强制 DIRECT，一个走你指定的代理组。
>
> 插件只申请代理设置和本地存储权限，不读取网页、密码和浏览记录。
>
> 源码、部署和回滚说明都放在仓库里。使用前记得把代理组名改成你自己的，并检查两个端口没有被占用。

## 镜头清单

1. 国内网站走错代理后打不开的画面（不要展示账号）。
2. Chrome 工具栏弹窗：蓝色“代理模式”、绿色“直连模式”。
3. 点击“直连”，刷新国内页面成功。
4. 点击“代理”，用公开 IP 查询页展示出口变化。
5. 快速扫过 Git 仓库目录和 MIT 许可证。

## 发布前脱敏

- 使用全新的 Chrome 演示配置文件。
- 隐藏书签栏、账号头像和其他扩展。
- Clash 画面不要露出订阅地址、流量、节点名称。
- 不展示公司内网、税务账号、店铺后台或邮箱。
